What is an AVIF file, and why won't it open?

AVIF stands for AV1 Image File Format. It's built on the same video tech as the AV1 video codec, and it can make photos up to half the size of a JPG without losing visible quality. That's why so many websites now serve their images as AVIF — smaller files mean faster pages.

The catch is that it's still fairly new. Older apps were built before AVIF existed, so they don't know what to do with it. Your phone or computer might be perfectly fine and still show you a blank icon, just because the app you're using hasn't caught up yet.

The file itself is fine. You don't need to re-download it or fix it — you just need an app or a tool that speaks AVIF.

  1. Check what app you're using to open it — old apps are the usual problem.
  2. Try your browser first — most modern browsers open AVIF with no fuss.
  3. If that works, the file is fine and your photo app is the problem.
  4. If nothing opens it, convert it to JPG and move on.

How to open AVIF files on Windows

Windows 11 handles AVIF pretty well these days. Windows 10 is where people usually hit trouble — and it's almost always the missing AV1 extension, not the file.

One thing to check: make sure Windows is up to date. Microsoft has been adding AVIF support through updates, so an old install is more likely to complain. Run Windows Update once, and the Photos app might just start working.

  • Photos app — on Windows 11, the Photos app opens AVIF files out of the box. On Windows 10, you might need the free AV1 Video Extension from the Microsoft Store first. If Photos shows an error, that's the missing piece.
  • Chrome, Edge, or Firefox — drag the file into a browser window and it just opens. This is the fastest check when you're not sure if the file is the problem.
  • Paint — newer versions of Paint on Windows 11 can open and save AVIF files too. Handy if you want to crop or resize while you're at it.
  • Convert it — if your favourite app still won't touch it, convert the AVIF to JPG with the free online tool and use the JPG instead.

How to open AVIF files on Mac

Macs have had it easier than Windows here. If you're on a recent macOS, you probably won't even notice AVIF files — they just open.

Where it gets tricky is older Macs. If your Mac is running macOS Catalina or older, Preview won't know what an AVIF file is. In that case, your browser is the quickest way to look at it, and converting to JPG is the fix if you need to actually use the picture.

  • Preview — macOS Big Sur and newer open AVIF files in Preview, no extra software needed. Double-click the file and it shows up like any other photo.
  • Safari — Safari 16 and newer open AVIF files in a tab, just like any other image.
  • iPhone or iPad photos — if the file came from your phone, it should open in Photos already. Apple added AVIF support a while back, and newer iOS versions handle it fine.
  • Convert it — on an older Mac that won't open AVIF, converting to JPG is the easy answer. The online tool works in your browser, so nothing to install.

How to open AVIF files on Android and iPhone

Phones are mostly fine with AVIF now, as long as the software is reasonably recent. The trouble usually shows up on older phones, or when a photo arrives through an app that doesn't pass the format through properly.

And here's a small tip: if someone sends you an AVIF file on WhatsApp or in a chat and it won't open, save it to your phone first, then try opening it from your gallery. Chat apps sometimes mangle file types on the way through.

  • Android — Android 12 and newer open AVIF files in the Photos app and in Chrome. Older Android versions might show a blank thumbnail, so convert the file to JPG if yours won't open.
  • iPhone — iOS 16 and newer open AVIF in Photos and Safari. If the file came from a website, long-press it and save it, then open it from Photos.
  • In the browser — on either phone, open the file in Chrome or Safari and it'll show up. No app needed.
  • Convert on your phone — if your gallery app won't open it, use the free AVIF to JPG tool right in your phone's browser. Pick the file, convert, download the JPG, done.

If your AVIF file still won't open

  • Try a different app first — if Photos won't open it, try your browser. If the browser won't either, the file may be the problem, not your device.
  • Download it again — a download that got cut off can leave you with half a file. Grab a fresh copy and try again.
  • Check the file size — if the file is 0 KB or suspiciously tiny, it never downloaded properly.
  • Convert it to JPG — this is the fix that works no matter what. Even if the file opens in your browser, a JPG copy means you can use it in any app, send it to anyone, and upload it anywhere.
  • Rename it — and this one sounds silly, but check the file actually ends in .avif. A file saved without its extension can confuse some apps.

Frequently asked questions

Can I open an AVIF file in my browser?

Yes. Most modern browsers — Chrome, Edge, Firefox, and Safari 16 and newer — open AVIF files right in a tab. Just drag the file into a browser window and it will show up.

Do I need to install anything to open AVIF files?

In most cases, yes. If your photos app or file viewer is up to date, it will probably handle AVIF already. Older versions — Windows 10 Photos without the AV1 extension, or macOS before Big Sur — are the ones that tend to struggle.

Why won't my AVIF file open?

Usually it means the app you're using doesn't support AVIF yet, or the file didn't download fully. Try opening it in your browser first. If that doesn't work either, the file itself might be damaged — try downloading it again.

What should I do if my device can't open AVIF files?

Can I convert AVIF to JPG on my phone?

What is an AVIF file, anyway?

AVIF is a newer image format that squeezes photos into much smaller files than JPG, while keeping them looking just as good. Websites love it because pages load faster — which is why you keep running into it. Your device just needs an app that knows how to read it.
